# FastTasks — Sistema de Cadastro de Tarefas

**Organize suas tarefas. Simplifique seu dia.**

## Descrição
O FastTasks é um sistema simples de cadastro e organização de tarefas feito com Vue.js.
Funciona localmente, sem banco de dados e sem backend.

## Objetivo acadêmico
Praticar componentes Vue, diretivas, eventos, `props` e `emits`, além de trabalhar com Git e GitHub (branches, commits, push, pull, Pull Requests e merge).

## Tecnologias utilizadas
- Vue.js 3
- JavaScript
- HTML5 e CSS3
- Vite (para executar o projeto)
- Git e GitHub

## Funcionalidades implementadas
- Cadastrar tarefa (não aceita campo vazio)
- Listar tarefas com o status de cada uma
- Marcar como concluída e desfazer
- Excluir tarefa
- Contadores de total, pendentes e concluídas
- Mensagem quando a lista está vazia
- Filtro por status: Todas, Pendentes e Concluídas

## Instalar as dependências
```bash
npm install
```

## Executar o projeto
```bash
npm run dev
```
Abra o endereço mostrado no terminal (http://localhost:5173).
